# Informe de ejemplo

Documento ficticio creado para probar el conversor. No contiene información de ninguna empresa real.

## Objetivo

Verificar que la conversión conserva **la estructura**, el *énfasis* y las tablas del documento original.

## Alcance

El documento cubre tres frentes de trabajo, en este orden de prioridad:

- Control de documentos por lotes
- Registro de cada conversión con fecha y origen
- Revisión manual de las tablas convertidas

## Resumen de datos
